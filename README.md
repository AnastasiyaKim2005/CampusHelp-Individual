CampusHelp-University Student Service Request Portal
Project Overview:
CampusHelp is a web-based university service request portal. The system will allow students to submit service requests, track progress, and receive status updates. Administrators will be assign requests, update status, and monitor requests progress.
Project Objectives:
1. Keep all requests in one place
2. Make it easier to track and manage requests
3. Help administrators to handle requests
4. Let students check their request and its status
Main features:
1. Students can subnit requests
2. Requests will be divided into categories
3. Each request has a unique ID
4. Administrators can assign requests
5. Students can see updates of their requests
6. Administrators can track requests through dashboard
Project Duration:
10 days
