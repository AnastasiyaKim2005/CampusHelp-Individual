Functional Requirements:
1. Students can submit requests using an online form
2. Students can choose from IT support, classroom maintenance, library assistance and administrative services
3. Students can select priority
4. Each request receives a unique ID
5. Administrators can assign requests to staff members
6. Students can check the status of the request
7. Administrators can change the status of the request

Non-functional requirements:
1. The system should be easy to use
2. Student information should be secured
3. Screen should respond quickly
4. Information should be displayed correctly

Acceptance Criteria: 
1. Students can fill and submit requests
2. Students can select categories and priorities
3. Each request has a unique ID
4. Students can see request status
5. Administrators can view and manage requests
