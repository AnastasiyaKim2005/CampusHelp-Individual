1. Change Request Information
ID: CR01
Requested by: University Administration
Request: Automatic Email Comfirmation
2. Description: The administration wants students to receive an automatic email after submitting a service request. The email should confirm that the request was successfully submitted and include its unique request ID.
3. Scope Impact: The original project included submitting and tracking requests but did not include real email integration. Therefore, this request is an additional feature outside the original project scope.
4. Cost Impact:
Additional Estimated Hours: 3 hours
Hourly Rate: 50,000 UZS
Additional Cost: 150,000
Original Budget: 2,250,0000 UZS
New Budget: 2,400,000
5. Schedule Impact: Adding this feature would require extra time for planning, development, setup and testing. This could delay the prototype and final testing.
6. Risk Impact:The main risk is that the extra work could delay project completion because the project has a limited schedule.
7. Recommendation: DEFER
